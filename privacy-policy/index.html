TubeGuard 개인정보처리방침

최종 업데이트: 2024년 10월

핵심 요약: TubeGuard는 사용자 데이터를 외부 서버로 전송하지 않습니다. 모든 데이터는 사용자의 기기에만 저장됩니다.

1. 앱 소개

TubeGuard는 보호자가 자녀의 YouTube, TikTok 등 소셜 미디어 앱 사용을 관리할 수 있는 자녀 보호 앱입니다. 본 방침은 TubeGuard가 수집하는 정보와 사용 방식을 설명합니다.

2. 수집하는 정보

TubeGuard는 앱 기능 제공을 위해 다음 정보를 기기 내에만 저장합니다:

  • PIN 정보: 보호자가 설정한 PIN의 암호화된 해시값 (암호화하여 기기에 저장, 원본 PIN은 저장하지 않음)
  • 차단 설정: 앱 차단 활성화 여부, VPN 사용 여부
  • 차단 기록: 앱 차단 이력 (최대 100건, 기기 내 저장)
  • 타이머 설정: 일일 허용 사용 시간 및 타이머 상태

3. 수집하지 않는 정보

  • 개인 식별 정보 (이름, 이메일, 전화번호 등)
  • 위치 정보
  • 기기 고유 식별자 (광고 ID 등)
  • 브라우저 기록 또는 검색 내용
  • 차단된 앱에서의 실제 콘텐츠

4. 데이터 저장 및 보안

모든 앱 데이터는 Android의 EncryptedSharedPreferences(AES256-GCM 암호화)를 사용하여 기기 내부 저장소에 암호화되어 저장됩니다. 데이터는 인터넷을 통해 전송되거나 외부 서버에 저장되지 않습니다.

5. 사용하는 권한 및 목적

  • VPN 권한: DNS 수준에서 특정 앱의 인터넷 접근을 차단하기 위해 사용합니다. TubeGuard의 VPN은 실제 외부 VPN 서버에 연결하지 않으며, 기기 내에서 DNS 쿼리(도메인 이름 조회)만 필터링합니다. 사용자의 실제 인터넷 트래픽(검색 내용, 웹 페이지 내용 등)을 수집하거나 저장하지 않습니다.
  • 접근성 서비스(Accessibility Service): 보호자가 설정한 차단 대상 앱이 실행될 때 즉시 차단 화면을 표시하는 자녀 보호 기능을 구현하기 위해 사용합니다. 접근성 서비스를 통해 수집한 화면 정보는 앱 차단 여부 판단에만 사용되며, 기록하거나 외부로 전송하지 않습니다.
  • 기기 관리자(Device Admin): 자녀가 앱을 강제로 삭제하는 것을 방지합니다. PIN 없이는 기기 관리자 권한을 해제할 수 없습니다.
  • 부팅 수신: 기기 재시작 후 차단 서비스를 자동으로 복원하기 위해 사용합니다.

6. 제3자 서비스

TubeGuard는 앱 안정성 개선을 위해 Firebase Crashlytics를 사용할 수 있습니다. 크래시 발생 시 기기 정보 및 오류 로그가 Google Firebase 서버로 전송될 수 있습니다. 이 데이터에는 개인 식별 정보가 포함되지 않습니다.

Firebase 개인정보처리방침: https://firebase.google.com/support/privacy

7. 아동 개인정보 보호 (COPPA 준수)

TubeGuard는 보호자가 사용하는 자녀 보호 앱입니다. 본 앱은 아동의 개인 정보를 수집하지 않으며, 아동 관련 데이터를 외부로 전송하지 않습니다. 본 앱은 미국 아동 온라인 개인정보 보호법(COPPA) 및 관련 아동 개인정보 보호 법규를 준수합니다. 13세 미만 아동의 개인정보는 수집하지 않습니다.

8. 데이터 삭제

앱을 삭제하면 기기에 저장된 모든 앱 데이터(설정, PIN, 차단 기록)가 완전히 삭제됩니다. 앱 내 설정에서도 모든 데이터를 초기화할 수 있습니다.

9. 방침 변경

본 개인정보처리방침은 변경될 수 있으며, 변경 시 이 페이지에 업데이트됩니다.
